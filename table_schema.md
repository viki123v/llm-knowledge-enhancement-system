## 5. Complete data dictionary



### 5.1 Raw review file


| Raw field                   | Type and format                              | Meaning / identifier role                      | Planned treatment                                                                    | Leakage, duplication, bias, and linkage risks                                                                                                  |
| --------------------------- | -------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `rating`                    | Float, 1.0–5.0; e.g. `5.0`                   | Explicit preference and interaction label      | Retain. Preserve raw value; derive `is_positive = rating >= 4` for implicit ranking. | Strong positive skew. Do not treat low ratings as merely “not observed.”                                                                       |
| `title`                     | Nullable string                              | Review headline; review content                | Rename `review_title`; retain only when text is used.                                | Must not be confused with product `title`. Validation/test text can leak held-out preference.                                                  |
| `text`                      | Nullable string                              | Review body; interaction content               | Retain in a split-aware text store; normalize whitespace, not meaning.               | May contain personal information, unsupported claims, or post-purchase facts. Never use held-out review text to predict that same interaction. |
| `images`                    | List of image dictionaries                   | User-uploaded review media                     | Record count for audit; drop URLs from MVP modeling.                                 | Availability/copyright/privacy risks; additional download cost.                                                                                |
| `images[].small_image_url`  | Nullable URL string                          | Small review-image URL                         | Drop from MVP.                                                                       | Remote mutable content.                                                                                                                        |
| `images[].medium_image_url` | Nullable URL string                          | Medium review-image URL                        | Drop from MVP.                                                                       | Same.                                                                                                                                          |
| `images[].large_image_url`  | Nullable URL string                          | Large review-image URL                         | Drop from MVP.                                                                       | Same.                                                                                                                                          |
| `images[].attachment_type`  | String, usually `IMAGE`                      | Attachment kind                                | Drop from MVP.                                                                       | Low recommendation value.                                                                                                                      |
| `asin`                      | String, Amazon variant ID; e.g. `B088SZDGXG` | Identifies the exact reviewed variant          | Retain as `variant_asin` for traceability, not as the main item key.                 | Multiple variants can share one parent; modeling both levels would duplicate product families.                                                 |
| `parent_asin`               | String; e.g. `B08BBQ29N5`                    | Parent product-family ID and metadata join key | Retain as canonical `item_id`.                                                       | Correct key for metadata. Do not join raw `asin` to parent-level metadata.                                                                     |
| `user_id`                   | Pseudonymous string                          | Identifies reviewer/user                       | Retain; map deterministically to contiguous integer for models.                      | No demographic meaning. Treat as sensitive pseudonymous data.                                                                                  |
| `timestamp`                 | Integer Unix epoch in milliseconds           | Time review was recorded                       | Retain as int64 and derive UTC datetime.                                             | Review time is not guaranteed purchase time. Tie handling must be deterministic.                                                               |
| `helpful_vote`              | Nonnegative integer                          | Number of helpful votes                        | Retain only for audit; exclude from main features.                                   | May accumulate after the review, creating temporal leakage and popularity bias.                                                                |
| `verified_purchase`         | Boolean                                      | Amazon's purchase-verification flag            | Retain for audit/sensitivity analysis; do not require it in the main task.           | Filtering changes the population and may remove legitimate interactions. Semantics are platform-defined.                                       |


The website's illustrative JSON uses older-looking names such as `sort_timestamp` and `helpful_votes`, while its field table, loader, and inspected Musical Instruments records use `timestamp` and `helpful_vote`. The actual file schema governs processing.

### 5.2 Product metadata file


| Raw field                        | Type and format                                          | Meaning / KG role                                              | Planned treatment                                                                                      | Leakage, duplication, bias, and linkage risks                                                           |
| -------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| `main_category`                  | Nullable string                                          | Broad Amazon domain                                            | Retain for audit/filtering; optionally one KG edge distinct from fine categories.                      | Contains cross-domain contamination; not a trusted label by itself.                                     |
| `title`                          | Nullable string                                          | Product name; item text                                        | Retain and normalize whitespace; primary text input.                                                   | Seller-written, sometimes keyword-stuffed; near-duplicates across products.                             |
| `average_rating`                 | Nullable float                                           | Aggregate rating shown at crawl time                           | Retain only for descriptive audit; **drop from model, KG, prompts, and embeddings**.                   | Direct target leakage and future aggregation relative to historical splits.                             |
| `rating_number`                  | Nullable integer                                         | Aggregate rating count shown at crawl time                     | Retain only for audit; **drop from model inputs**.                                                     | Popularity and future-information leakage.                                                              |
| `features`                       | List of strings                                          | Bullet-point product features; item text / attribute evidence  | Retain, deduplicate exact bullets, concatenate with length limit.                                      | Seller claims can be repetitive or incorrect. Metadata snapshot may postdate historical interactions.   |
| `description`                    | List of strings                                          | Product-description fragments; item text / attribute evidence  | Retain, remove empty/exact duplicate fragments, concatenate with length limit.                         | Same snapshot and seller-claim risks; can duplicate `features`.                                         |
| `price`                          | Nullable float or rare raw string; USD according to docs | Crawl-time product price                                       | Parse valid floats and retain for audit; exclude from primary model.                                   | 60.24% missing, time-varying, and possibly unavailable/variant-specific.                                |
| `images`                         | List of image dictionaries                               | Product media                                                  | Keep only main-image URL/count if later needed; drop from MVP model.                                   | Copyright, broken URLs, and multimodal cost.                                                            |
| `images[].thumb`                 | Nullable URL string                                      | Thumbnail                                                      | Drop from MVP.                                                                                         | Remote mutable content.                                                                                 |
| `images[].large`                 | Nullable URL string                                      | Large image                                                    | Drop from MVP.                                                                                         | Same.                                                                                                   |
| `images[].hi_res`                | Nullable URL string                                      | High-resolution image                                          | Drop from MVP.                                                                                         | Same.                                                                                                   |
| `images[].variant`               | Nullable string such as `MAIN`, `PT01`                   | Image position/type                                            | Retain only if selecting one main image later.                                                         | Not a product variant ASIN.                                                                             |
| `videos`                         | List of dictionaries                                     | Product videos                                                 | Drop from MVP.                                                                                         | Low coverage and high processing cost.                                                                  |
| `videos[].title`                 | Nullable string                                          | Video title                                                    | Drop from MVP.                                                                                         | Can add noisy text.                                                                                     |
| `videos[].url`                   | Nullable URL string                                      | Video URL                                                      | Drop from MVP.                                                                                         | Remote content and rights concerns.                                                                     |
| `videos[].user_id`               | Nullable string                                          | Video contributor ID                                           | Drop.                                                                                                  | Not the review `user_id`; avoid accidental identity linkage.                                            |
| `store`                          | Nullable string                                          | Store/seller-facing name                                       | Retain separately; normalized node for `sold_by_store`.                                                | Not guaranteed to equal brand; 3.17% disagreement where both were observed.                             |
| `categories`                     | Ordered list of strings                                  | Product's hierarchical Amazon category path                    | Retain ordered values; construct category nodes, product assignments, and adjacent parent–child edges. | 8.88% missing; inconsistent capitalization or taxonomy placement is possible.                           |
| `details`                        | Heterogeneous string-to-value dictionary                 | Product attributes such as brand, material, size, model, color | Preserve raw JSON; extract only a versioned whitelist of useful keys.                                  | Keys/types vary. Aggressive flattening creates false equivalences and huge noisy relation vocabularies. |
| `details.Brand`                  | Usually nullable string                                  | Manufacturer/brand-like attribute                              | Normalize conservatively and create `has_brand` when present.                                          | Only 58.09% coverage; aliases and seller errors. Do not fill from `store` automatically.                |
| `details.UPC`                    | Usually string                                           | Universal Product Code candidate                               | Retain for audited exact external linking only.                                                        | Only 0.08% coverage; preserve leading zeros and validate checksum/format before use.                    |
| Other whitelisted `details` keys | Scalar or list-like, key-dependent                       | Candidate typed KG attribute                                   | Normalize units/casing per relation; retain raw evidence.                                              | Relation meaning may vary by category; validate coverage and collision rate before acceptance.          |
| `parent_asin`                    | String                                                   | Unique metadata item ID                                        | Retain as canonical primary key.                                                                       | Main link from interactions. Audit uniqueness before every run.                                         |
| `bought_together`                | Officially list, observed all null                       | Intended bundle/recommendation links                           | Drop for this category.                                                                                | Zero measured coverage; cannot be silently replaced with co-review edges.                               |
| `subtitle`                       | Rare nullable string; observed in actual file            | Extra title information for book/sheet-music-like rows         | Preserve raw for audit; drop from MVP due to rarity.                                                   | Not in the published core metadata table; may signal mixed content.                                     |
| `author`                         | Rare nullable string/dictionary; observed in actual file | Author information for book/sheet-music-like rows              | Preserve raw for audit; drop from MVP.                                                                 | Heterogeneous type and extremely low coverage.                                                          |




### 5.3 0-core and 5-core rating-only files


| Field         | Type and example        | Role                                      | Planned treatment                   | Risks / linkage                                                   |
| ------------- | ----------------------- | ----------------------------------------- | ----------------------------------- | ----------------------------------------------------------------- |
| `user_id`     | String                  | User primary key                          | Map to canonical user ID.           | Same caveats as raw reviews.                                      |
| `parent_asin` | String                  | Item primary/foreign key                  | Rename `item_id`; join to metadata. | Confirm join coverage after any sample/filter.                    |
| `rating`      | Float 1.0–5.0           | Explicit target and positive-event source | Preserve and derive `is_positive`.  | Same threshold and skew caveats.                                  |
| `timestamp`   | Int64 Unix milliseconds | Event order and split key                 | Preserve and convert to UTC.        | Tie-break deterministically by stable row hash or original order. |


Official processing deduplicates a `(user_id, parent_asin)` pair by retaining the earliest review before creating rating-only data. If raw data is processed independently, replicate that policy exactly or document a deliberately different policy. Do not compare results across incompatible deduplication rules.
